## 1. 总体技术路线

本工程以 STM32F4 单片机为核心控制器，基于 Keil MDK、STM32F4 标准外设库和 FreeRTOS 实现多任务调度。系统启动流程为 [`main()`](USER/main.c:1) 调用 [`systemInit()`](BALANCE/system.c:1) 完成外设初始化，再由周期控制任务调用 [`Contest_Task_Update()`](BALANCE/contest_task.c:1161) 统一调度赛题状态机。

硬件执行层采用两轮差速底盘，左轮映射为 MotorD、右轮映射为 MotorA，利用编码器完成速度反馈，电机 PWM 完成速度闭环输出。滚球控制使用摄像头获取钢球位置，舵机通过 TIM8 CH4 / PC9 输出 PWM 调节轨道倾角。红外循迹采用 9 路红外传感器，读取为 9bit 掩码后计算线路偏差。

整体思路为：

- 底盘运动：编码器测速 + 速度 PI + 差速目标速度分配。
- 路径跟踪：9 路红外加权误差 + PID 修正 + IMU yaw 辅助直行纠偏。
- 滚球稳定：视觉位置反馈 + 一阶低通 + PID + IMU 加速度前馈 + 舵机限幅输出。
- 任务组织：按键选择任务，使用统一状态机完成启动、运行、完成、故障停车和 OLED 显示。

## 2. 循迹算法实现

循迹模块位于 [`track_ir.c`](HARDWARE/track_ir.c:1) 和 [`track_control.c`](BALANCE/track_control.c:1)。9 路红外从左到右赋予权重 -4 至 +4，读取黑线有效掩码后，通过加权平均计算线路中心偏差。核心思想是：有效通道越偏左，误差越负；越偏右，误差越正；中心通道有效时误差接近 0。

循迹控制中，线路误差经 [`Track_PID_UpdateError()`](BALANCE/track_control.c:53) 得到转向差速量，再叠加到左右轮目标速度：左轮为基础速度减修正量，右轮为基础速度加修正量，从而实现差速转向。若短时丢线，则根据上一次线路误差方向继续搜索；若达到超时或宽线判定条件，则触发停止请求。

在整圈任务中，直线段没有完全依赖红外，而是融合 IMU yaw 角进行直行纠偏。直线阶段由 yaw PID 和红外线 PID 按比例混合；弯道阶段主要使用红外 PID，并加入固定弯道前馈差速，使小车更容易通过半圆弯道，红外反馈只修正残余偏差。

## 3. 滚球稳定算法实现

滚球模块位于 [`ball_control.c`](BALANCE/ball_control.c:1) 和 [`ball_control.h`](BALANCE/ball_control.h:1)。摄像头通过 USART1 上传钢球位置，位置单位为 0.1mm，目标位置由任务状态机给定，例如中心 0、+5cm 为 500、-5cm 为 -500。

控制流程如下：

1. 摄像头位置先经过一阶低通滤波，滤波系数 alpha 初值为 0.25，用于降低视觉噪声。
2. 根据目标位置与滤波位置计算误差。
3. 使用位置 PID 输出目标轨道倾角，PID 输出单位按角度理解。
4. 读取 IMU 加速度并按前馈系数补偿小车加减速带来的钢球惯性偏移。
5. 对目标角度进行限幅、死区处理和变化率限制。
6. 将角度映射为舵机 PWM，输出到 TIM8 CH4 / PC9。

实际参数中，舵机中位、最大最小 PWM、输出角限幅、变化率限制均在 [`Ball_Control_Init()`](BALANCE/ball_control.c:69) 中集中设置。稳定判据使用连续稳定计数：当绝对误差小于阈值并连续满足指定周期后，认为钢球到达稳定状态。

## 4. 赛题任务状态机设计

赛题状态机集中在 [`contest_task.c`](BALANCE/contest_task.c:1) 和 [`contest_task.h`](BALANCE/contest_task.h:1)。任务编号通过宏定义管理，按键短按切换任务，长按启动或停止。公共状态包括空闲、启动、运行、完成和停止。

### 任务 1、任务 2

任务 1用于电机调试，给左右轮固定目标速度，用于验证编码器方向、电机极性和速度 PI 参数。任务 2用于舵机调试或滚球中心保持调试，便于确认舵机中位、控制方向和 PWM 输出范围。

### 整圈循迹任务

整圈循迹任务采用阶段式路径状态机，阶段包括第一段直行、第一个半圆、第二段直行、第二个半圆和最终停车。直线段通过编码器积分里程切换阶段，并叠加 yaw 角纠偏；弯道段通过红外循迹和编码器弧长判定完成。总里程达到设定值后停车并冻结计时。

### 静态滚球任务

静态滚球任务依次控制钢球到达 +5cm、-5cm 等目标位置。每个阶段都调用滚球闭环，判断稳定后进入下一目标位置；若阶段超时，也会切换或进入保护状态，保证比赛流程可继续执行。

### 合并任务 4~6

任务 4、5、6统一为“循迹 + 滚球保持”的合并任务框架。该框架不重复编写三套循迹逻辑，而是复用整圈循迹路径服务，仅通过参数配置实现不同任务：

- 任务 4：A 到 B，滚球保持 0cm。
- 任务 5：A 到 A 整圈，滚球保持 0cm。
- 任务 6：A 到 A 整圈，滚球保持指定整数刻度。

合并任务运行分为预平衡和运动两个核心阶段。启动后先启用滚球闭环，电机保持停止；钢球稳定保持一定时间后，再启动循迹并开始运动计时。这样可避免起步时钢球尚未稳定导致大幅偏移。运动过程中继续调用滚球闭环，并对循迹速度进行保守限制和慢启动处理。

## 5. 安全保护与调试设计

工程中加入了多层保护机制：

- 电机目标速度统一通过 [`Contest_Task_ClearMotion()`](BALANCE/contest_task.c:90) 清零，保证停止状态可靠。
- 红外循迹模块可根据宽线、超时、丢线等条件触发停止。
- 合并任务设置预平衡超时、运动超时和故障停车状态。
- 舵机输出包含 PWM 限幅、角度限幅、死区和变化率限制，降低机械撞限和抖动风险。
- OLED 显示任务号、阶段、计时、红外状态、滚球误差、舵机 PWM 等关键调试信息，方便现场快速定位问题。

## 6. 实践创新点

1. 采用统一赛题状态机框架：将任务选择、运行、完成、失败停车统一管理，避免各任务重复编写控制流程。
2. 任务 4~6复用同一合并框架：通过路径模式和滚球目标参数区分任务，降低代码复杂度，提高调试一致性。
3. 预平衡后再起步：先让钢球达到目标位置并稳定保持，再开始运动计时和循迹，提高移动过程中滚球稳定性。
4. 循迹与 IMU 融合：直线段同时使用红外线误差和 yaw 角纠偏，弯道段加入前馈差速，使直线和半圆段控制更稳定。
5. 滚球控制加入 IMU 前馈：在视觉 PID 基础上补偿小车加减速引起的惯性扰动，提升移动保持能力。
6. 采用比赛导向的轻量化设计：没有重构底层框架，而是在现有 FreeRTOS 周期任务中集中调度，模块少、路径清晰，便于现场快速调参。

## 7. 可用于报告的一句话总结

本项目基于 STM32F4 和 FreeRTOS 构建两轮差速滚球小车控制系统，通过“红外循迹 + 编码器里程 + IMU 姿态辅助”实现路径跟踪，通过“视觉位置 PID + IMU 加速度前馈 + 舵机 PWM 限幅”实现钢球稳定，并采用统一赛题状态机完成多任务切换、预平衡、运动计时与安全停车，具有结构简洁、调试直观、比赛适应性强的特点。
